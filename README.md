## 🧩 Problem-Solving Approach

For every problem, I try to follow:

1. Understand the problem
2. Identify input and output
3. Think about the brute-force solution
4. Identify the pattern
5. Optimize the approach
6. Write clean Java code
7. Analyze Time Complexity
8. Analyze Space Complexity
9. Test edge cases
10. Review mistakes
